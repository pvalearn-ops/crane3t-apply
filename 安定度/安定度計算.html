二、後方安定度

依據移動式起重機安全檢查構造標準第17條第一項第一款：伸臂中心線之鉛直面與起重機之行駛方向成直角時，位於伸臂所在側支點上之重量，應為起重機重量之百分之十五以上。

Ra ≧ 0.15 × Wb ，∵ Ra ＝ L1 × Wb / B1 ∴ L1 / B1 ≧ 0.15
⇒ L1 / B1 ＝ - / - ＝ - -

依據第17條第一項第二款：伸臂中心線之鉛直面與起重機之行駛方向一致時，位於伸臂所在側支點上之重量，應大於起重機重量之百分之十五與平均輪距和軸距之比值之乘積。

Rb ≧ 0.15 × Wb × B / H ，∵ Rb ＝ L2 × Wb / H ∴ L2 / B ≧ 0.15
⇒ L2 / B ＝ - / - ＝ - -

附件1　伸臂重心計算

伸臂長度為各伸出狀態之伸臂總長；伸臂重量、油壓缸重量依節輸入。下表各伸出狀態之伸出比例、重心位置與重心 d 依計算方式自動計算。

伸臂重心計算方式：
  1. 計算第 n 節吊桿重心位置 ＝ Σ(第 n 節伸臂長度 × 第 n 節伸出比例) － 第 n 節伸臂長度 ／ 2
  2. 計算油壓缸重心位置 ＝ Σ(第 n 節伸臂長度 × 第 n 節伸出比例) － 第 n 節伸臂長度 ＋ Σ(第 n+1 節伸臂長度 × 第 n+1 節伸出比例)2
  3. 重心位置 ＝ Σ(第 n 節伸臂重心位置 × 第 n 節伸臂重量) ＋ Σ(第 n 節油壓缸重心位置 × 第 n 節油壓缸重量)伸臂總重 ＋ 油壓缸總重

伸出比例：有油壓缸之節（第 1～油壓缸支數節）依序全伸（1）或未伸（0）；其餘同步伸縮之節，伸出比例 ＝ (伸出節數 － 油壓缸支數) ／ (伸臂節數 － 油壓缸支數)。

前端等價質量計算方式：
  1. 第 n 節起點 ＝ Σ(第 1～n 節伸臂長度 × 伸出比例) － 第 n 節伸臂長度；終點 ＝ Σ(第 1～n 節伸臂長度 × 伸出比例)。油壓缸終點取至第 n+1 節。
  2. 超出重心之長度：終點 ＜ 重心 d 時為 0；起點 ＞ 重心 d 時為（終點 － 起點）；其餘為（終點 － 重心 d）。重心 d 依附件1 各伸出狀態之重心。
  3. 伸臂前端等價質量 Wp′ ＝ Σ(第 n 節超出重心之長度 ／ 第 n 節伸臂長度 × 第 n 節伸臂重量)
  4. 油壓缸前端等價質量 Wp″ ＝ Σ(第 n 支超出重心之長度 ／（終點 － 起點）× 第 n 支油壓缸重量)
  5. 伸臂重量中之前端等價質量 Wp ＝ (Wp′ ＋ Wp″) ／ 1000（公噸）
